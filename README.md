## 📌 About This Project

This is my personal Data Science and Machine Learning portfolio, built to showcase my projects, skills, and journey as I work toward a career in data science and data engineering. 
It includes sections on my background, technical skills (Python, SQL, Pandas, statistical analysis, and machine learning), 
and case studies from real projects, including exploratory data analysis on retail and YouTube creator datasets, a statistical analysis project supporting a medical research study, 
and my own open-source Python library, smilo, published on PyPI. The site is fully responsive, animated, and designed with a modern dark theme.

## 🤖 Built With Claude AI

This entire portfolio was built using **Claude AI** (by Anthropic), an AI assistant that can write and edit code through natural conversation.
You don't need to be an expert coder to make something like this yourself. 
Just go to claude.ai, describe what you want in plain English (for example: "build me a personal portfolio website with a hero section, project cards, and a contact section"),
and Claude will generate the full code for you. You can keep chatting with it to refine the design, add new sections, fix wording, or change anything else, until it looks exactly the way you want.

You can also ask for a completely different color theme instead of the violet/purple one used here, 
for example, emerald green, ocean blue, warm amber/sunset, coral pink, or crimson red, and Claude will restyle the entire site to match.
Once you're happy with the result, save the file as `index.html` and upload it to GitHub Pages to make it live for free, just like this one.
