# Fahad Hameed | Portfolio

My personal portfolio website, built to showcase my work as a Data Scientist and Data Engineer in training.

**Live site:** [dsfahad.github.io/portfolio.fahad](https://dsfahad.github.io/portfolio.fahad/)

## About

This is a single-page portfolio covering my skills, projects, and background in Data Science, Data Engineering, and Machine Learning. It is built entirely with vanilla HTML, CSS, and JavaScript, with no frameworks or build tools required.

## 🤖 Built With Claude AI

This entire portfolio was built using **Claude AI** (by Anthropic), an AI assistant that can write and edit code through natural conversation.
You don't need to be an expert coder to make something like this yourself. 
Just go to claude.ai, describe what you want in plain English (for example: "build me a personal portfolio website with a hero section, project cards, and a contact section"),
and Claude will generate the full code for you. You can keep chatting with it to refine the design, add new sections, fix wording, or change anything else, until it looks exactly the way you want.
for example, emerald green, ocean blue, warm amber/sunset, coral pink, or crimson red, and Claude will restyle the entire site to match.
## Features

- Animated hero section with a typewriter effect and particle canvas background
- Monochrome dark theme with a cyan accent
- Interactive terminal-style skills section
- Project cards with staggered flying entrance animations and morph hover effects
- Clickable project cards that open a detailed modal (approach, tools, outcome, links)
- Animated timeline in the About section
- Contact section with a particle convergence animation
- Fully responsive layout

## Tech Stack

- HTML5
- CSS3 (custom properties, animations, gradients)
- Vanilla JavaScript (Canvas API, Intersection Observer)
- Google Fonts: Space Grotesk, Inter, JetBrains Mono

## Project Structure

```
portfolio.fahad/
├── index.html
└── README.md
```

Everything (markup, styles, and scripts) lives in a single `index.html` file for simplicity.

## Run Locally

No build step required. Clone the repo and open the file directly in a browser:

```
git clone https://github.com/DSFAHAD/portfolio.fahad.git
cd portfolio.fahad
open index.html
```

Or serve it locally with any static server, for example:

```
python -m http.server
```

## Deployment

This site is deployed via GitHub Pages directly from the `main` branch.
